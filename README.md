## ✨ Overview

Winter smog and toxic air pollution spikes disproportionately impact vulnerable populations—children, the elderly, outdoor workers, and individuals with respiratory conditions. **VayuSaathi** bridges the gap between raw air quality data and life-saving family actions.

Key capabilities planned:
- **Hyper-Local Air Quality Intelligence:** Multi-pollutant tracking (PM2.5, PM10, AQI, NO2, Weather & Wind).
- **Personalized Vulnerability Profiles:** Actionable alerts tailored for infants, elderly relatives, and asthmatics.
- **Smart Indoor & Outdoor Action Guidance:** Real-time air purifier schedules, ventilation windows, and mask recommendations.
- **Community Smog Reporting & Alerts:** Neighborhood pollution hotspot warnings and collective awareness.

## 🛠️ Quickstart & Setup

### Prerequisites
- Node.js (v18.x or later)
- npm / pnpm / yarn
- Python 3.10+ (if running backend data/ML services)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<YOUR_GITHUB_USERNAME>/vayusaathi-smog-copilot.git
   cd vayusaathi-smog-copilot
   ```

2. **Install dependencies:**
   ```bash
   # Frontend / Fullstack
   npm install
   ```

3. **Configure Environment Variables:**
   ```bash
   cp .env.example .env.local
   # Update environment variables with your API keys
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open in Browser:**
   Visit [http://localhost:3000](http://localhost:3000) to see the application.
